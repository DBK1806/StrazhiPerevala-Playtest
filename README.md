# Стражи перевала

Пробная версия игры для Windows x64. Защитите ворота в десяти уровнях двух глав.

**[Скачать игру для Windows](https://github.com/DBK1806/StrazhiPerevala-Playtest/releases/download/v0.1.0/StrazhiPerevala-Playtest-0.1.0-Windows-x64.zip)**

Распакуйте ZIP целиком и запустите **StrazhiPerevala.exe**. Godot устанавливать не нужно. У каждого игрока свой прогресс, в начале доступен первый уровень.
